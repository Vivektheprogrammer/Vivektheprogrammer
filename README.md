## 🚀 Featured Projects

### 1. NetBoost — Network Optimization Utility

A Windows network optimization utility designed to make downloads smarter and network usage smoother.

* Parallel segmented download acceleration using HTTP Byte Ranges.
* Intelligent streaming-priority bandwidth coordination.
* Real-time network monitoring, latency and jitter tracking.
* DNS benchmarking and optimization.
* Chrome and Edge companion extension.

**Tech:** Rust, Tokio, Tauri 2, React, TypeScript, SQLite.

🔗 [Repository](https://github.com/Vivektheprogrammer/NetBoost)

### 2. Morph — Offline File Conversion Utility

A lightweight, privacy-focused file conversion and editing utility designed around Windows context-menu integration.

* Offline-first file conversion.
* Support for multiple document and image formats.
* File merging, rearranging and editing capabilities.
* Context-menu-first workflow.
* Local file processing without mandatory cloud services.

**Tech:** Rust, Windows APIs, Desktop Development.

🔗 [Repository](https://github.com/Vivektheprogrammer/Morph)

### 3. PlateShare — Food Donation Platform

A food donation and sharing platform connecting donors, including restaurants and hotels, with people in need.

**Tech:** Python, Flask.

🔗 [Repository](https://github.com/Vivektheprogrammer/PlateShare)

### 4. Spam Classifier

An email and SMS spam classification project using machine learning algorithms and text vectorization.

**Tech:** Python, Scikit-learn, TF-IDF, ExtraTreesClassifier.

### 5. ForecastIQ

Machine learning models for temperature and rainfall prediction.

### 6. PoetByte — Poetry & Creative Writing
